# AREVÉ web typography

Derived from the user-supplied Playfair Display and Poppins masters in Brand Identity Package v7. Latin, Latin Extended, punctuation and currency subsets are served as WOFF2. Original glyph design and copyright/licensing metadata are retained. Internal family names are Areve Serif Web / Areve Sans Web to distinguish these subsets from the reserved original names. See OFL_License.txt and the embedded font copyright records.

Source guidance: https://openfontlicense.org/webfonts-and-reserved-font-names/
